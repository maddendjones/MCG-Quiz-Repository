Import Questions

Paste formatted questions below. Headings formatted as Folder / Subfolder / Sub-subfolder will be parsed and nested automatically.

Each question needs a Question N line, lettered choices (A., B., … as many as you need), and an Answer: X line. Optional: Order: First / Second / Third, Difficulty: Easy / Medium / Hard, explanations (any length), an objective, and Reference: with a Library page title or folder to show those pages after the question is answered. Load or download the sample to see every part. Re-importing a question updates it instead of duplicating it.

Backup & Export

Saves every question plus your answers, flags and test history in one file. Restore it on any browser or computer to pick up where you left off.

Plain text in the same format as Import Text, including all explanations. Questions only, no progress.
