Import Questions

Paste formatted questions below. Headings formatted as Folder / Subfolder / Sub-subfolder will be parsed and nested automatically.

Each question needs a Question N line, lettered choices (A., B., … as many as you need), and an Answer: X line. Explanations can run over several lines. Questions you've already imported are updated rather than duplicated.

Backup & Export

Saves every question plus your answers, flags and test history in one file. Restore it on any browser or computer to pick up where you left off.

Plain text in the same format as Import Text, including all explanations. Questions only, no progress.

Manage & Delete Bank Questions

Deletes only questions within the selected path without affecting other folders.

Permanently deletes every question, answer, flag and saved test in this browser. Download a backup first if you might want them back.
